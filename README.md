單檔網頁，免安裝、免網路即可使用：**直接用瀏覽器打開 `index.html`**（或把單一 HTML 檔傳給客戶）。

- 預覽：`preview.png`
- 資料年份：2026 年（民國 115 年），2025-12-12 公告
- 資料來源：Workforce 勞動力量《2026 年（民國 115 年）勞健保保費及勞退提繳三合一費用對照參考用表》

## 功能

| 操作 | 結果 |
|---|---|
| 在「月薪資總額」輸入金額 | 自動對應投保級距（未達整級以較高級計算），即時顯示單位／員工應繳 |
| 從「或直接選擇投保級距」下拉 | 直接鎖定某一級（82 級全部列出） |
| 點下方「完整級距對照表」任一列 | 套用該級距並回到頁首 |
| 選「健保眷屬人數」 | 員工健保自付 ×(1+眷屬)，超過 3 人以 3 人計 |
| 勾「加入職業災害保險費」並填費率 | 以職災投保薪資（29,500～72,800）概估，計入單位負擔 |
| 「複製試算結果」 | 把級距、員工、單位、合計與明細複製成純文字（可直接貼 LINE） |
| 「列印／存 PDF」 | 輸出乾淨的 A4 版面 |

## 計算基礎

- 勞保（含就業保險）：費率 12.5%，勞工 20%／雇主 70%（投保薪資上限 45,800、下限 11,100）
- 全民健康保險：費率 5.17%，勞工 30%／雇主 60%（雇主負擔含平均眷口數 0.56；投保金額下限 29,500、上限 313,000）
- 勞工退休金：6%，雇主全額（上限 150,000、下限 1,500）
- 工資墊償基金：0.025%，雇主全額
- 金額一律以「月」（30 日）計，**不含**職業災害保險（職災依行業別費率，可於進階選項加計）

## 更新資料（換年度時）

1. 用編輯器打開 `index.html`，找到 `var ROWS = [`（約在第 500 行附近）。
2. 每列格式：
   `[級數, 投保級距, 勞保-勞工, 勞保-雇主, 墊償-雇主, 健保-勞工, 健保-雇主, 勞退-雇主, 合計-勞工, 合計-雇主, "備註"]`
   級數填 `0` 表示「低薪／部分工時級」（無級數編號）。
3. 存檔後執行驗證：

   ```powershell
   node .\_verify.js
   ```

   會檢查：欄位數、級距是否遞增、合計是否等於各項加總、級數是否連續、
   與法定公式回推是否相符（±1 元）、級距判定邏輯、抽樣對照。

4. 同步更新頁尾的「試算基礎」費率與 `index.html` 內的 `<title>`／頁首年份。

## 注意

- 本頁僅供試算參考，實際金額以勞保局、健保署核定為準。
- 到職或離職當月未足月：勞保按日計收、健保按月計收。
- 本表適用一般本國人；外籍人士、部分工時、兼職等情況另有規定。
