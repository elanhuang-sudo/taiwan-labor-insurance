## 功能

| 操作 | 結果 |
|---|---|
| 在「月薪資總額」輸入金額 | 自動對應投保級距（未達整級以較高級計算），即時顯示單位／員工應繳 |
| 從「或直接選擇投保級距」下拉 | 直接鎖定某一級（82 級全部列出） |
| 點下方「完整級距對照表」任一列 | 套用該級距並回到頁首 |
| 選「健保眷屬人數」 | 員工健保自付 ×(1+眷屬)，超過 3 人以 3 人計 |
| 勾「加入職業災害保險費」並填費率 | 以職災投保薪資（29,500～72,800）概估，計入單位負擔 |
| 「複製試算結果」 | 把級距、員工、單位、合計與明細複製成純文字（可直接貼 LINE） |
| 「列印／存 PDF」 | 輸出乾淨的 A4 版面 |

## 計算基礎

| 項目 | 費率 | 分擔 | 級距上下限 |
|---|---|---|---|
| 勞工保險（普通事故＋就業保險） | 11.5% ＋ 1% ＝ **12.5%** | 勞工 20%／雇主 70%／政府 10% | 11,100 ～ 45,800 |
| 全民健康保險 | **5.17%** | 勞工 30%／雇主 60%（雇主含平均眷口 0.56 人，合計 1.56 人）／政府 10% | 29,500 ～ 313,000 |
| 勞工退休金（新制） | **6%** | 雇主全額 | 1,500 ～ 150,000 |
| 積欠工資墊償基金 | **0.025%**（萬分之 2.5） | 雇主全額 | 按勞保投保薪資總額 |
| 職業災害保險 | 依行業別費率 | 雇主全額 | 29,500 ～ 72,800 |

金額一律以「月」（投保日數 30 日）計。勞保費**不含**職業災害保險（可由進階選項加計）。

# 工具二：租金扣繳與二代健保補充保費試算（`/rent/`）

公司向**個人**承租房屋時，給付租金要代扣所得稅與補充保費。此頁把兩種常見租約寫法分開處理。

- 檔案：`rent/index.html`（單檔、可離線使用）
- 網址：`https://tool.kscpb.com/rent/`

## 兩種情境

| 情境 | 租約寫法 | 算法 |
|---|---|---|
| **房東實拿**（稅外加） | 「房東每月實收 X 元」 | 租金總額 = X ÷ (1 − 10% − 2.11%)，稅費由公司額外負擔 |
| **租金含稅**（內扣） | 「租金 X 元（含稅）」 | 稅費從 X 中扣除，房東實拿 = X − 扣繳 − 補充保費 |

## 兩個門檻（重點，容易算錯）

| 項目 | 費率 | 免扣門檻 |
|---|---|---|
| 所得稅扣繳 | 居住者 **10%**／非居住者 **20%** | 每次應扣繳稅額 ≤ 2,000 元 → 租金未達 **20,010 元**免扣 |
| 二代健保補充保費 | **2.11%** | 單次給付未達 **20,000 元**免扣 |

> 兩者門檻不同，這是多數人算錯的地方。例：租金 20,000 元 → 扣繳 2,000 元「不超過」2,000 所以**免扣**，
> 但補充保費 422 元**要扣**。

## 數字驗證

```powershell
node rent\_verify.js
```

會驗證：

- 與原始 Google 試算表對照（20,000 含稅 → 扣繳 0、保費 422、實拿 19,578）
- 房東實拿 20,000 → 總額 22,755、扣繳 2,275、保費 480
- 門檻邊界（20,000 / 20,010 / 19,999）
- 非居住者 20% 情境
- 恆等式：實拿 ＋ 扣繳 ＋ 補充保費 ＝ 租金總額 ＝ 公司支出
- 回推驗證：實拿 → 總額 → 反算實拿（誤差 ≤ 1 元）

## 注意

- 假設房東為**個人**（免開發票）。若為營業人開立發票，另有 5% 營業稅，不在本試算範圍。
- 管理費、水電費等另行約定者，本頁僅就租金本身計算。
- 僅供參考，實際以稽徵機關及健保署認定為準。

# 工具三：薪資所得扣繳稅額試算（`/withholding/`）

依**財政部北區國稅局**官方「115 年度薪資所得扣繳稅額表」查每月應扣繳稅額，
並支援**非居住者**的 6%／18% 扣繳率判斷。

- 檔案：`withholding/index.html`（單檔、可離線使用）
- 網址：`https://tool.kscpb.com/withholding/`

## 居住者：三種扣繳方式

| 方式 | 適用 | 算法 | 起扣點 |
|---|---|---|---|
| **有填免稅額申報表** | 員工已填表載明扶養親屬 | 查稅額表（依薪資＋扶養人數） | 表已內含 2,000 元門檻 |
| **未填／免填申報表** | 按 5% 扣繳 | 全月給付總額 × 5% | **40,020**（稅額 > 2,000 才扣） |
| **兼職／非每月給付** | 兼職所得、非按月給付 | 每次給付額 × 5% | **90,501**（無扶養者起扣點） |

> 兩個 5% 的起扣點不同，是《薪資所得扣繳辦法》第 7 條規定的：
> 按月給付看「每月稅額是否超過 2,000 元」，兼職看「每次給付是否達起扣點」。

## 非居住者：6% 或 18%，只看金額

依《各類所得扣繳率標準》**第 3 條第 1 項第 2 款**：非居住者薪資按給付額扣 **18%**，
但全月薪資給付總額在每月基本工資 **1.5 倍以下**者扣 **6%**。

| 全月給付總額 | 扣繳率 |
|---|---|
| ≤ **44,250 元**（115 年基本工資 29,500 × 1.5） | **6%** |
| \> 44,250 元 | **18%** |

- 非居住者**不適用**免稅額申報表與扶養親屬人數。
- 非居住者**沒有** 2,000 元免扣門檻（稅額 1 元也要扣）。
- 繳款期限是**代扣日起 10 日內**（比居住者的次月 10 日更短）。
- 判斷基準：一課稅年度在台居留、停留合計**滿 183 天**為居住者，未滿則為非居住者。

> 基本工資若調整，門檻跟著變。程式中的 `NR_BASE_WAGE`（29,500）改一個數字即可，
> 門檻 `NR_THRESHOLD` 會自動算成 1.5 倍。

## 資料重建（換年度時）

稅額表有 840 列 × 12 欄，**不要手動編輯**。改走建置腳本。

> **為什麼建置用 ODS、網站只給 PDF？**
> 各區國稅局提供的稅額表是同一份財政部檔案（已用 SHA256 比對北區與中區的
> 115 年度 PDF，兩者完全相同）。北區只提供 PDF，但 PDF 解析容易受版面影響；
> ODS 是結構化資料，解析穩定得多。
> 因此**建置時**用任一區提供的 ODS 解析，**網站上**只顯示北區的 PDF 連結。

```powershell
# 1. 取得當年度的 ODS（北區若無 ODS，可用其他區提供的同一份檔案）
#    115 年度 ODS（中區國稅局）：https://www.ntbca.gov.tw/download/8a42e9511ba449fe84b5264292a636f7
curl -L -o wh.ods "<當年度 ODS 網址>"

# 2. 解析 ODS → 注入樣板 → 產生網頁
python build\withholding-from-ods.py wh.ods

# 3. 驗證（會擋下資料錯誤，未通過就不會寫檔）
node withholding\_verify.js
```

腳本會同時更新 `verify/official-withholding-115.json`（官方資料快照）。

| 檔案 | 用途 |
|---|---|
| `build/withholding-template.html` | 網頁樣板（含 `__TABLE_DATA__` 標記） |
| `build/withholding-from-ods.py` | **主要建置路徑**：解析 ODS |
| `build/withholding-from-pdf.py` | 備援路徑：直接解析 PDF（含完整性驗證） |

兩條路徑我都實際跑過，產出的 HTML 與 JSON **SHA256 完全相同**，可互相驗證。

## 注意

- 查表模式僅適用月薪 **80,001～500,000 元**；低於 80,001 元稅額為 0，超過 500,000 元以最高列計算。

- 免扣繳仍須**列單申報**；同一人全年給付不超過 1,000 元者免申報。
- 本頁只算所得稅扣繳，不含勞健保費、勞退自提等其他扣除。
- 員工**未實際填寫**免稅額申報表時，公司不得逕行按扶養人數查表，應改用 5% 方式（頁面會提示）。
